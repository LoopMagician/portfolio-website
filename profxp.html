Security

Penetration Tester - Converge Technology solutions (May 2024 - August 2024)

Penetration testing is a job that requires a lot of attention to detail. There is no step-by-step guide on how to approach a new client's web application and it is up to the tester to find the vulnerabilities and exploit them. This is the job in which I was tasked with during my time at the company.

The learning experience that I had that summer was extensive. Penetration testing requires that the tester has a good understanding of the web application and the different components used within the application. From there, testing required testing different kinds of attacks tailored to the application. The types of attacks in which I learned and executed during my experience included SQL injection, XSS, CSRF attacks and many more niche types of attacks like race conditions and upload vulnerabilities. I was fortunate to be able to use my skills against real clients and deliver them the vulnerabilities in which I found during testing, informing them how they can be reproduced and what needed to be done to fix them.

This was a great experience not only in the fact that I garned extensive technical experience in cybersecurity, but it also allowed me to gain experience with client interaction. I believe it is just as important to know how to deliver the vulnerabilities to the client as it is to be able to find them. My experience also introduced me to tools like BurpSuite and Kali Linux, which includes tools like Nmap, Metasploit, SQLMap and much more that I was able to gain some experience with as well.
